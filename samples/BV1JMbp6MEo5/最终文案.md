## 一、引入：为什么要区分 memory 的种类

人靠记忆积累经验，而在 agent 里也有一类能力叫做 memory。人的大脑会整理事情，最终形成记忆；agent 则可以借助大模型和外部存储，保存整理好的 memory，在需要时取出来使用。都是记忆，有什么区别吗？

为了搞明白这个问题，我在本地搭建了一个小型的 agent，然后给这个 agent 依次加上了业界主流的 memory——也就是工作记忆、语义记忆、情景记忆和程序性记忆。我想知道 memory 对于整个 agent 有什么样的影响。

我相信只要你看完这个视频，对这个问题心里是会有清晰的认识的。下面让我们愉快地开始吧。

## 二、工作记忆：当前会话怎么串起来

首先明确一个事实：**大模型是一个无状态的机器**。换句话说，当我们第一次给模型对话的时候，模型会返回结果；但是下一次对话的时候，agent 需要把历史对话放回上下文——因为上一次对话的状态内容，大模型是没记住的，需要我们再次把之前的对话内容发送给模型。

比如我们打开一个 Codex 会话，我先告诉 Codex 我吃素，然后问它去北京有什么吃的推荐；第二次我没有再提吃素，但它的回答考虑了这个偏好。看这里，我通过 Codex 原生 trace 获取的输入，这里除了我提到的内容，前面的对话也在这里——模型读到了前文，整个会话才能串起来。而这正是 agent **working memory（工作记忆）**的工作原理。

当前会话是可以通过工作记忆来维护的，但是**不同会话之间的交互，靠工作记忆是不行的**，所以这时候就需要有长期记忆了。

## 三、长期记忆的三种分类

按保存的内容，可以把长期记忆分成三类：**语义记忆、情景记忆和程序性记忆**。接下来我们把它们加入同一个客服 agent，看看处理结果会有什么变化。

为了讲清楚这三种长期记忆，我在本地搭建了一个电商客服 agent。

### 3.1 语义记忆：记住用户的偏好

首先我们先看语义记忆的作用。在之前这个电商客服 agent 有过交流：我买耳机主要用来通勤，预算 800 元以内，优先考虑降噪和佩戴舒适度。agent 把这些偏好整理出来，存进数据库。

过了几天，我开启一段新会话问"最近有什么耳机推荐"，有了语义记忆，它就能取出这些偏好，结合当前商品信息进行推荐——比如先筛选 800 元以内的耳机，再把适合通勤、降噪和佩戴表现符合需求的产品排在前面。

这就是语义记忆：**记住用户的偏好，在下一次交流时用上**。

### 3.2 情景记忆：记住过去发生过什么

接下来再看一下情景记忆。情景记忆保存的是某次经历。比如我买了一副耳机，但是发现没声音，第一次找 agent 对话时，他让我重启、重新配对；我试过了，问题没有解决，后面我也没再次处理。而 agent 会把这次处理的经过保存下来——哪笔订单出了问题，尝试了什么，结果怎样。

第二天，我重新启动一个 agent 会话继续帮我处理昨天那副耳机。没有这段记忆，客服可能需要问之前做过哪些排查；有了情景记忆，它就能取出上次的记录，放进模型的上下文，继续处理。

这就是情景记忆的作用：**记住过去发生过什么，让下一次处理接得上**。

我们在终端跑一下情景记忆，可以看到通过情景记忆可以省很多时间——比如第二次的会话已经读取到了上次的情景记忆，我们的客服 agent 就能处理上次没完成的事情。

### 3.3 程序性记忆：保存可复用的做事方法

最后看程序性记忆，我们可以把它理解成处理问题时使用的 **SOP**。

还是拿耳机举例：如果我想退货，这个耳机真的坏掉了需要退换，但是 agent 该按什么流程办理？所以这时候就需要给 agent 一份售后流程——有货办理换货，没货先询问用户愿意等待还是咨询退款。agent 需要把这份流程保存下来，遇到适用的情况就取出来放进模型的上下文，模型根据流程和工具返回的结果，决定下一步动作。

这就是程序性记忆的作用：**保存可复用的做事方法，指导后续任务的执行**。

## 四、总结

以上就是我们通过三个例子展示的三种长期记忆。我们也总结一下：

| 类型 | 保存什么 | 例子 | 回答的问题 |
|---|---|---|---|
| **语义记忆** | 事实和偏好 | 我买耳机的预算是多少、看中降噪还是舒适度 | 我知道什么 |
| **情景记忆** | 某次经历 | 上次耳机出了什么问题、试过哪些方法、结果怎样 | 我经历过什么 |
| **程序性记忆** | 可复用的做事方法 | 办理换货时有货怎么处理、缺货怎么处理 | 我该怎么做 |

对 agent 来说，它们分别回答三个问题：**我知道什么？我经历过什么？我该怎么做？**

如果你用过 LangChain 框架，LangChain 的长期记忆也是按照这种方式进行分类的。

另外，记忆的写入和读取也是一个挺有意思的话题。如果你感兴趣，可以在评论区聊一下。
