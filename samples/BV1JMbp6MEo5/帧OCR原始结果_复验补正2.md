## 二、复验结果：8/8 全部判定错误

| 帧 | 原记录 | 复验实有内容（节选） |
|---|---|---|
| [01:00] | 空 | `promte1` / `LLM` / `response1` / `第一次对话` / **`大模型是没记住的 需要我们再次`** |
| [01:20] | 空 | **整段 JSON**（`"text": "我吃素"` / `"去北京旅行，有什么吃的推荐？"`）+ `获取的输入` |
| [04:00] | 空 | `PostgreSQL` / `检索退换流程` / `退换耳机` / `执行退换` / `决定下一步动作` |
| [04:40] | 空 | `语义记忆` / `情景记忆` / `具体经历` / `比如 上次耳机出了什么问题` |
| [05:00] | 空 | `我知道什么?` / `我经历过什么?` / `我该怎么做?` / **`LangChain 的长期记忆也是按照`** |

（第一册已复验的 `[02:20]` `[02:40]` `[03:00]` 同为实有内容。）

> **结论：原 OCR 的 8 个"空"判定无一为真（100%）**，属**系统性静默失败**，而非"画面确实无字"。

**交叉验证**：`[01:00]` 与 `[05:00]` 用**两个独立视觉模型**复跑 ——
`qwen3.5:9b` 与 `ornith-1.5:9b` —— **结论一致**，排除单模型幻觉。

## 三、连带影响：成品里一条「推断」其实有据

`最终文案.md` L122 的纠错条目：

> `launcha 框架 / luncha` → **LangChain** ｜ ⚠️ **推断**：…**该处无画面文字可核（[05:00] 帧空白）**

而 `[05:00]` **实测有 `LangChain 的长期记忆也是按照`**（两模型一致）。

⇒ 该条目「无实据」的**前提不成立**；论断本身**成立**。依据栏可由「推断」升级为
「[05:00] 画面文字」。**但修订已交付成品属内容决策，本册不代改，留用户拍板。**

另：成品画面补充表把 `[01:00]` `[01:20]` 标为「（无文字）」，而它们实为**工作记忆章节的核心演示画面**
（prompt/response 往返、整段 JSON 输入）—— 属**漏报**：把有证据处写成无证据。
与"编造"方向相反，但同样是**证据失配**，且会误导读者以为该处无线索。

## 四、方法论教训（写进 SKILL.md 的那条，再补一句）

抽帧方式会改变结论：`[02:40]` 用 `--at` 精确 seek 取到**过渡帧**（仅标题卡），
而 `fps=1/20` 采样取到**有内容帧**。演示类画面内容**瞬变**，±1 帧即跨屏。

> 因此本册所有结论均以**多帧/多模型交叉**为准，不以单次单点采样定案。
