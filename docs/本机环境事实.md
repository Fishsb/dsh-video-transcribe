## 二、主路线（✅ 本轮端到端实跑通过）


## 三、宿主 ASR 的真实返回语义（2026-09-25 实测，调用方必须按此判成败）

| 情形 | HTTP | 响应体 |
|---|---|---|
| 成功 | 200 | `{"ok":true,"text":"…"}` |
| PCM 数据非法 / 非 16k wav | 200 | `{"ok":false,"code":"ASR_LOCAL_FAILED","message":"Cannot read properties of null (reading 'sampleRate')"}` |
| 缺 `data:audio/wav;base64,` 前缀 | 200 | `{"ok":false,"code":"BAD_AUDIO"}` |

> **判据：必须看 `ok` 字段，不能看 HTTP 状态码**（失败也是 200）。`vt_pipeline.py` 已按此判并抛错。
> 30s 音频实测 5.6–12 秒；314 秒音频切片后总耗时约 100 秒。

## 五、B站接口实测语义（2026-09-25）

| 接口 | 结果 | 注意 |
|---|---|---|
| `/x/web-interface/view` | code=0，含 title/aid/cid/duration/owner/stat | 无 cookie 可用 |
| `/x/tag/archive/tags` | code=0，本例 10 个标签 | 无 cookie 可用 |
| `/x/v2/reply`（type=1&oid=aid&sort=2&ps=20） | code=0，本例 3 组热评 | 无 cookie 可用 |
| `/x/v1/dm/list.so?oid=cid` | HTTP 200，返回标准弹幕 XML | **Content-Encoding 声明 deflate 但实体是明文** → 解码须按候选顺序试，不能只按声明解 |
| `/x/player/playurl`（fnval=16） | code=0，dash.audio 3 条（65694/77456/111858 bps） | 取最低 bandwidth 即够转写 |

**弹幕为空是正常结果**：本例 `danmaku_count: 0`，必须**显式写 0**，不得静默缺字段。
